public / public static
private / private static
protected / protected static
internal / internal static

These acces modifers can be assigned to Classes which are present in the namespace and
for methods whic are present class

private / private static
	private members can be accessed with in the class,They can't be accessed outside of the class.
	private members can't inherited.

protected / Protected static
	Protected members of a class can be accessed with in the class, can't be accessed outside of the
	class.
	Protected members can be  Inherited.

internal / interanl static

Internal members can be accessed with in the class , out side of the class, they can't accesed
outside of the namespace.
Internal members can be Inherited.


public / public static :
	public members of class can be accessed inside  the class,ouside of the class, and outside namespace
	public members can be Inherited.
